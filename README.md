
# Drone Detection Using Python and AI

## Overview

This is an ongoing project focused on exploring drone detection
using Python, Artificial Intelligence, and Computer Vision.

The goal is to develop a practical system that can identify drones
in images or video using suitable computer vision and machine
learning techniques.
